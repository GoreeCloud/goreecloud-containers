# GoreeCloud Containers — Branding

## Product names

- **Product:** GoreeCloud Containers
- **Core backend:** GoreeCloud Container Engine
- **Development CLI executable:** `goree`
- **Repository:** `GoreeCloud/goreecloud-containers`

Use these names consistently in product and repository documentation. A future daemon/service name must not be treated as established until implemented and packaged.

## Positioning

GoreeCloud Containers is a first-party GoreeCloud OCI-compatible container engine and workload-platform project. It should be represented as original GoreeCloud software that interoperates with open container standards and mature OCI runtime foundations.

## Current lifecycle wording

Until separate evidence changes the state, use wording such as:

- Development
- Development-only CLI/source
- OCI-compatible direction or OCI configuration/runtime foundation
- `crun`/`runc` runtime targets

Do not describe the current source as production-ready, Stable, OCI-conformant, rootless-accepted, or a Docker replacement.

## Third-party names

Docker, Podman, `crun`, `runc`, OCI, and other third-party names are used only to describe interoperability, dependencies, or migration context. Their trademarks, logos, product identity, and trade dress are not GoreeCloud branding.
